# AEDP3消融实验设计方案

## 🎯 **实验目标**
验证注意力机制在AEDP3中的作用，特别是：
1. **注意力通道**（Channel 0/1/2）的独立和组合贡献
2. **AttentionFieldEncoder**相较于标准PointNet编码器的优势
3. **早期融合 vs 晚期融合**的特征融合策略效果

## 📋 **实验变体设计**

### **A. 基准线变体**
| 变体ID | 名称 | 注意力通道 | 编码器策略 | 目的 |
|--------|------|-----------|------------|------|
| **DP3** | 原始基准 | 无 | PointNet++ (3D坐标) | 对比基础性能 |
| **AEDP3-Full** | 完整AEDP3 | Channel 0+1+2 | 晚期融合: AttnEncoder + PointNet++ | 完整系统性能 |

### **C. 编码器融合消融**
| 变体ID | 名称 | 通道组合 | 融合策略 | 输入维度 | 预期验证 |
|--------|------|----------|----------|----------|------------------|
| **AEDP3-Late** | 晚期融合 | Channel 0+1+2 | attn→AttnEncoder<br>+ pc→PointNet++<br>→ 特征拼接 | attn: [3,512]<br>pc: [3,512] | 当前实现：分别编码后融合 |
| **AEDP3-Early** | 早期融合 | Channel 0+1+2 | attn+pc→拼接<br>→ PointNet++ | [6,512] | 早期融合：拼接后统一编码 |

#### **融合策略详细说明**

**晚期融合 (Late Fusion) - 当前实现**:
```
注意力场 [3,512] → AttentionFieldEncoder → 特征A [64]
点云 [3,512] → PointNet++ → 特征B [64]
特征A + 特征B → 最终特征 [128]
```

**早期融合 (Early Fusion) - 新对比**:
```
注意力场 [3,512] + 点云 [3,512] → 拼接 → [6,512] → PointNet++ → 最终特征 [64]
```

**优势对比**:
- **晚期融合**: 允许不同模态使用专门的编码器，特征维度更大
- **早期融合**: 模态间早期交互，可能学习到更复杂的跨模态特征，但特征维度较小
